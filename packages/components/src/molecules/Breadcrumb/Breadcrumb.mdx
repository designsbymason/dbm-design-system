<VisuallyHidden asChild><h2>Intro</h2></VisuallyHidden>

<ComponentHeader title="Breadcrumb" tier="Molecule" />

A breadcrumb trail shows where the current page sits in a site — the path from the top down to the
page a reader is on, as a row of links ending in the page itself. A compound component: put one
`Breadcrumb.Item` per level inside `Breadcrumb`, each holding a `Breadcrumb.Link` (or, for the last
one, `Breadcrumb.Page`). It renders a `<nav>` around an ordered list, and draws the separators
between items itself.

Choose how big the trail is with `size`, and what sits between items with `separator`. A trail that
is too wide for its container wraps onto more lines; with `maxItems`, its middle collapses into a
"…" button that shows the rest when used. `Breadcrumb.Link` is the `Link` atom underneath, so it
handles external addresses and `disabled`, and takes `asChild` to render a router's own link.

### Import

```tsx
import { Breadcrumb } from "@dbm-design-system/components";
```

## Properties

Every part reads `size` and `separator` from `Breadcrumb`, so they are set once, on the root. `ref`
forwards to the `<nav>`. Also accepts any other native `<nav>` attribute beyond what's listed here
(e.g. `dir`, `onFocus`) — passed straight through to the root element.

<PropertiesTable of={BreadcrumbStories} order={rootPropOrder} />

Only `Breadcrumb.Item` elements are rendered: a fragment, or plain text, placed among the children is
ignored (with a warning in development), so build the list from items directly rather than wrapping
several in a fragment.

### Breadcrumb.Item properties

One level of the trail — the `<li>`. It draws the separator after its content, except when it is the
last item. Also accepts any other native `<li>` attribute beyond what's listed here (e.g. `title`) —
passed straight through to the underlying element.

<PropertiesTable of={BreadcrumbItemStories} order={itemPropOrder} />

### Breadcrumb.Link properties

A link to a page above the current one. It is the `Link` atom, so it also takes `external`,
`disabled`, `asChild` and the native anchor props. Also accepts any other native `<a>` attribute
beyond what's listed here (e.g. `onClick`, `title`) — passed straight through.

<PropertiesTable of={BreadcrumbLinkStories} order={linkPropOrder} />

### Breadcrumb.Page properties

The current page: plain text marked `aria-current="page"`, so a screen reader announces it as the
current page. Also accepts any other native `<span>` attribute beyond what's listed here (e.g.
`title`) — passed straight through to the underlying element.

<PropertiesTable of={BreadcrumbPageStories} order={pagePropOrder} />

## Usage guidelines

<div className="dbm-do-dont-grid">
<Callout tone="success" title="Do">

- Use a breadcrumb on a site or app with more than two levels of pages, so a reader can jump back up
  the hierarchy in one click.
- Put the trail near the top of the page, above the page's heading, on every page it applies to.
- End it with the current page as `Breadcrumb.Page`, so the reader can see where they are.
- Give each item the same name the page has in the navigation and as its own heading.
- Use `maxItems` on a deep hierarchy, so the trail keeps to a line or two on a narrow screen.
- Name the navigation with `aria-label` when a page holds more than one breadcrumb.

</Callout>
<Callout tone="danger" title="Don't">

- Don't use a breadcrumb as the main navigation, or to show the steps a reader has taken. It shows
  the site's structure, not their history — use `Tabs` or a stepper for sequences.
- Don't make the current page a link to itself; `Breadcrumb.Page` is deliberately not one.
- Don't put a breadcrumb on a top-level page with nothing above it.
- Don't add controls to an item other than the link — an item is one destination.
- Don't hide the trail on small screens; collapse it with `maxItems` instead, so the reader still has
  a way back up.
- Don't use a separator that reads as content, such as a word.

</Callout>
</div>

## Best practices

- The first item is usually the home page. An icon alone is enough for it when the link has an
  `aria-label` — `<Breadcrumb.Link href="/" icon={HouseIcon} aria-label="Home" />`.
- With a client-side router, use `asChild` on `Breadcrumb.Link` to render the router's own link, so
  navigation doesn't reload the page.
- Keep labels short. A label that is much longer than its neighbours wraps onto a second line inside
  its own item, which is fine, but a trail of long labels reads better collapsed.
- `maxItems` counts every item, including the first and the current page. It only collapses when
  at least two items would be hidden — replacing a single item with a button would help nobody.
- Every piece of text the component writes itself is in `labels`, so a translated site replaces the
  whole set in one place. The "…" button's name is a function of the number of hidden items.

## Accessibility

<Callout tone="info" title="A named navigation landmark holding an ordered list, with the current page marked">

The trail is a `<nav>` — a navigation landmark, named "Breadcrumb" (or your own name, through
`labels.navigation` or `aria-label`) so a reader who lists a page's landmarks can find it. Inside is
an ordered list, so a screen reader announces how many levels there are and which one it is on. The
list and its items state their `list` and `listitem` roles outright, because Safari with VoiceOver
otherwise stops treating a list with its markers removed as one. The current page carries
`aria-current="page"`. The separators are hidden from assistive technology: the list structure
already says everything they would.

| Key | Behaviour |
|---|---|
| `Tab` | Moves to the next link — each link, and the "…" button when there is one, is one stop |
| `Shift+Tab` | Moves to the previous one |
| `Enter` | Follows the focused link, or reveals the collapsed items from the "…" button |
| `Space` | Reveals the collapsed items from the "…" button |

Using the "…" button removes it from the page, so keyboard focus moves to the first item it
revealed rather than dropping to the top of the document. A disabled link stays in the tab order,
marked `aria-disabled`, matching WAI-ARIA guidance.

**Contrast**, measured in light and dark (the colours are the same in Purple and Emerald). A link is
`text.secondary`: 6.88:1 (light) and 10.47:1 (dark) on the surface, and 6.05:1 and 5.10:1 on the
canvas. A hovered link and the current page are `text.primary`: 14.11:1 and 13.53:1 on the surface,
12.41:1 and 6.59:1 on the canvas. The separators are `icon.default`: 4.70:1 and 8.21:1 on the
surface, and 4.13:1 (light) and 2.96:1 (dark) on the canvas — a hair under the 3:1 a graphic would
need in dark mode on the canvas, which the separators are exempt from since they are decorative and
repeat what the list structure and the spacing already show. A link isn't running through a paragraph, so the hover-only underline is
enough to mark it as a link; the current page is set apart by weight as well as colour.

</Callout>

## Code examples

```tsx
<Breadcrumb>
  <Breadcrumb.Item>
    <Breadcrumb.Link href="/" icon={HouseIcon}>Home</Breadcrumb.Link>
  </Breadcrumb.Item>
  <Breadcrumb.Item>
    <Breadcrumb.Link href="/products">Products</Breadcrumb.Link>
  </Breadcrumb.Item>
  <Breadcrumb.Item>
    <Breadcrumb.Page>Keyboards</Breadcrumb.Page>
  </Breadcrumb.Item>
</Breadcrumb>

{/* Built from your own data */}
<Breadcrumb>
  {trail.map((crumb, index) => (
    <Breadcrumb.Item key={crumb.href}>
      {index === trail.length - 1 ? (
        <Breadcrumb.Page>{crumb.label}</Breadcrumb.Page>
      ) : (
        <Breadcrumb.Link href={crumb.href}>{crumb.label}</Breadcrumb.Link>
      )}
    </Breadcrumb.Item>
  ))}
</Breadcrumb>

{/* A deep trail that collapses its middle */}
<Breadcrumb maxItems={4} itemsBeforeCollapse={1} itemsAfterCollapse={2}>
  {/* ... */}
</Breadcrumb>

{/* With a router: the router's own link carries the navigation */}
<Breadcrumb.Link asChild href="/products">
  <RouterLink to="/products">Products</RouterLink>
</Breadcrumb.Link>

{/* Translated */}
<Breadcrumb
  labels={{ navigation: "Fil d'Ariane", expand: (count) => `Afficher ${count} pages masquées` }}
  maxItems={4}
>
  {/* ... */}
</Breadcrumb>

{/* A native <a> attribute on Breadcrumb.Link, passed straight through */}
<Breadcrumb.Link href="/products" onClick={() => track("breadcrumb-products")}>Products</Breadcrumb.Link>
```
