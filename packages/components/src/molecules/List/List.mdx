<ComponentHeader title="List" tier="Molecule" />

An ordered or unordered list with a token-driven vertical gap between items and a configurable
marker style. Renders a `<ul>` by default, or `<ol>` via `as`. Use with
[`ListItem`](/docs/atoms-typography-listitem--docs) for children — a plain layout container on its
own, `List` composes with `ListItem`'s own icon marker, trailing content, and interactive/selected/
disabled states for nav-menu-style lists.

### Import

```tsx
import { List } from "@dbm-design-system/components";
```

## Usage guidelines

<div className="dbm-do-dont-grid">
<Callout tone="success" title="Do">

- Use the default `ul`/`disc` marker for plain, unordered content; switch `as="ol"` for genuinely
  sequential/ranked content (steps, rankings).
- Use `marker="none"` (with real content, e.g. a custom `icon` per item, or plain text in a
  nav-style list) rather than relying on `list-style: none` yourself — `List` also applies the
  `role="list"` fix Safari/VoiceOver need when the native marker is suppressed.
- Reach for `ListItem`'s own `icon`/`trailing`/`interactive`/`selected`/`disabled` props for
  nav-menu-style lists — see [`ListItem`](/docs/atoms-typography-listitem--docs) for the full set.
- Nest a `List` inside a `ListItem`'s own children for multi-level content — this is standard,
  unguarded HTML and needs no special prop.

</Callout>
<Callout tone="danger" title="Don't">

- Don't pass `start`/`reversed`/`type` without `as="ol"` — they're native `<ol>`-only attributes,
  silently ignored by the browser on the default `ul` (`List` warns about this in development).
- Don't expect `type` to do anything alongside an explicit `marker="disc"`/`"none"` override on an
  `ol` — it only applies when `marker` resolves to `"decimal"` (the default for `ol`), since it's
  translated into that same CSS `list-style-type` mechanism, not the native HTML attribute alone.
- Don't build a nav menu from scratch with `<div>`s and hand-rolled ARIA — `List` (`marker="none"`)
  plus `ListItem`'s `interactive`/`selected`/`disabled` already covers this correctly.

</Callout>
</div>

## Best practices

- `spacing` accepts a single spacing token step or a mobile-first responsive map keyed by
  breakpoint (e.g. `{ base: 1, lg: 6 }`) — the standard way to tighten/loosen list density at any
  breakpoint without a manual media query, matching `Grid`'s/`Stack`'s identical mechanism.
- `marker` has no single static default — it resolves to `"disc"` for the default `ul` and
  `"decimal"` for `ol`, matching native browser behavior, until explicitly overridden.
- `start`, `reversed`, and `type` are structural/native `<ol>` attributes, not tokenized design
  values — the same category as `GridItem`'s own `colSpan`/`rowSpan`/`colStart`/`rowStart`.

## Accessibility

<Callout tone="info" title="Safari/VoiceOver's list/listitem role fix, built in">

- When `marker="none"` suppresses the native marker, `List` automatically applies `role="list"`
  (and `ListItem` applies the matching `role="listitem"`) — Safari + VoiceOver (and historically
  other browser/AT combinations) drop the implicit list semantics once `list-style` is `none`;
  this is the standard, documented fix.
- `ListItem`'s own `interactive` rows render as a real, keyboard-activatable `role="button"` surface
  (Enter/Space, focus-visible styling) — see [`ListItem`](/docs/atoms-typography-listitem--docs)
  for its own full accessibility notes, including `selected`/`disabled`/accessible-name handling.
- Automated accessibility check verified against the default `ul`/`disc` case, `as="ol"`,
  `marker="none"` (the role fix itself), and a `marker="none"` list of `interactive` rows (selected/
  disabled included) — zero violations in every case.

</Callout>

## Code examples

```tsx
<List as="ol" spacing={2}>
  <ListItem>First step</ListItem>
  <ListItem>Second step</ListItem>
</List>
```

```tsx
// Ordered list counting down, lettered markers
<List as="ol" start={5} reversed type="A">
  <ListItem>Counts down from 5</ListItem>
  <ListItem>Then 4</ListItem>
</List>
```

```tsx
// Nav-menu-style list — no native marker, interactive rows with icons
<List marker="none">
  <ListItem interactive selected icon={HouseIcon} onClick={goHome}>Home</ListItem>
  <ListItem interactive icon={GearIcon} onClick={goToSettings}>Settings</ListItem>
</List>
```

```tsx
// A native <ul> attribute (title), passed straight through
<List title="Recent changes" spacing={2}>
  <ListItem>Item</ListItem>
</List>
```
