<VisuallyHidden asChild><h2>Intro</h2></VisuallyHidden>

<ComponentHeader title="HoverCard" tier="Molecule" />

A rich preview that opens when the pointer rests on a link (or keyboard focus lands on it) and closes
when it leaves — a profile on a username, a summary on a link — built on Radix HoverCard. Nothing is
clicked: the card is *supplementary*, an extra look at where the link leads. It is for pointer and
keyboard users on a screen wide enough to hover; it never opens on a touch screen. A compound
component: compose `HoverCard.Trigger` and `HoverCard.Content` inside `HoverCard` itself, with an
optional `HoverCard.Media` for an image across the top and an optional `HoverCardProvider` that
lets a run of cards share timing.

### Import

```tsx
import { HoverCard, HoverCardProvider } from "@dbm-design-system/components";
```

## Properties

`HoverCard` itself renders no DOM element of its own — it's a plain context provider around
`HoverCard.Trigger`/`HoverCard.Content` (matching Radix's own `HoverCard.Root`), so it has no
`className`/`style`/`id`/`data-testid`/`ref` of its own to accept.

### HoverCard.Trigger properties

(e.g. `download`, `hrefLang`, `onClick`) — passed straight through.

## Usage guidelines

<div className="dbm-do-dont-grid">
<Callout tone="success" title="Do">

- Use `HoverCard` for a quick look at where a link leads — a person's profile, a page summary, a
  repository's description — when the link already works perfectly well without the preview.
- Give `HoverCard.Trigger` a real `href`, usually through `asChild` with the `Link` atom. The card
  previews the destination; a trigger that goes nowhere has nothing to preview.
- Keep the card short: an avatar or image, a name, a line or two. Whatever it shows should also be
  on the page the link opens.
- Wrap a run of triggers (mentions in a paragraph, names in a table) in one `HoverCardProvider`, so
  moving along them opens each next card at once.
- Put `HoverCard.Media` first inside the content, so it can bleed out to the card's top edge.
- Use `disabled` for a row that doesn't need a preview right now, instead of unmounting the card.

</Callout>
<Callout tone="danger" title="Don't">

- Don't put anything in the card a user must reach: a button, a form, the only copy of a fact. It
  never opens on touch, and its buttons and links are removed from the tab order — use `Popover`.
- Don't use it for a short, plain-text label on an icon or control — that's `Tooltip`, which also
  names the control for assistive technology.
- Don't make the card the only place something is explained. A keyboard user can open it, but a
  screen reader's own navigation doesn't read it.
- Don't wrap a non-link in `HoverCard.Trigger` without giving it a way to take focus.
- Don't use `disabled` to hide a card you meant to remove — a disabled card still renders its trigger,
  and the preview is just gone.

</Callout>
</div>

## Best practices

- The default delays (`openDelay` 300, `closeDelay` 300) are a short beat, not an instant: a pointer
  passing straight over a link opens nothing, while one that rests on it gets the card quickly.
  Lengthen `openDelay` for a page dense with links, where sweeping the pointer across a paragraph
  would otherwise flash several cards, and keep `closeDelay` long enough to cross the gap onto the card.
- Pass `side`/`align` that suit the layout — a card under a link in the first column of a table
  reads better as `align="start"` than centred.
- Let `avoidCollisions` (on by default) handle the edges; it keeps the card inside the viewport and
  the content's width is capped so it never outgrows a phone-width screen.
- A small gap is fine: a transparent bridge across `sideOffset` is part of the card, so the pointer can
  cross from the trigger onto it without the card closing, however large the offset.
- Use `size` for how much room the content needs: `sm` for a name and a line, `lg` for a richer card.
- Use `hideWhenDetached` for a trigger in a scrolling list or table, so the card doesn't hover over
  empty space once its row scrolls away.

## Accessibility

<Callout tone="info" title="A preview for sighted pointer and keyboard users, not a dialog">

- The trigger is a link: `Tab` reaches it, and focus opens the card (after `openDelay`); moving
  focus away closes it (after `closeDelay`). `Escape` closes it and leaves focus on the link.
- The card follows the WCAG 1.4.13 pattern for content on hover or focus: it can be dismissed
  (`Escape`), it stays open while the pointer is over it, and it stays until the pointer or focus
  leaves.
- The card has no `role` and no accessible name, and nothing links it to the trigger — it is not
  announced when it opens, and a screen reader's own navigation does not reach it. Everything in it
  must be available on the page the link opens.
- Every focusable element inside the card is taken out of the tab order, so a keyboard user can't
  move into it. It is for reading, not for interacting.
- `disabled` leaves the trigger a working link and keeps the card shut for pointer and focus alike.
- Inside a `HoverCardProvider` only one card is open at a time, so a screen magnifier user never has two
  stacked previews to read.
- Text direction follows the page: the card is portaled to `body`, so it takes the direction set on
  the document, and `align="start"` lines up with the link's start edge in either direction. `side` is
  physical (`left` is the left of the link in both directions).
- In Windows high-contrast (forced colours) the card keeps its border and the arrow is drawn in the
  same system colours, so its edge still meets the card's.
- It does not open for a touch pointer, so on a phone or tablet a tap simply follows the link.
- A dev-mode console warning fires once per trigger if `HoverCard.Trigger` renders a plain `<a>`
  with no `href` or `tabIndex`, since a keyboard user could never open the card.

</Callout>

## Code examples

```tsx
<HoverCard>
  <HoverCard.Trigger asChild>
    <Link href="/people/jane">@jane</Link>
  </HoverCard.Trigger>
  <HoverCard.Content>
    <Text weight="semibold">Jane Doe</Text>
    <Text size="sm" color="secondary">Design systems engineer</Text>
  </HoverCard.Content>
</HoverCard>

{/* Quicker to open than the default, aligned to the link's start, opening beside it on large screens */}
<HoverCard openDelay={100} closeDelay={150}>
  <HoverCard.Trigger asChild>
    <Link href="/docs/tokens">tokens</Link>
  </HoverCard.Trigger>
  <HoverCard.Content align="start" side={{ base: "bottom", lg: "right" }}>
    <Text size="sm">Design tokens are the single source of truth for every value.</Text>
  </HoverCard.Content>
</HoverCard>

{/* A row of links sharing timing, with a default open delay of 500ms */}
<HoverCardProvider openDelay={500}>
  <HoverCard>
    <HoverCard.Trigger asChild>
      <Link href="/people/jane">Jane Doe</Link>
    </HoverCard.Trigger>
    <HoverCard.Content>
      <Text weight="semibold">Jane Doe</Text>
    </HoverCard.Content>
  </HoverCard>
  <HoverCard>
    <HoverCard.Trigger asChild>
      <Link href="/people/sam">Sam Lee</Link>
    </HoverCard.Trigger>
    <HoverCard.Content>
      <Text weight="semibold">Sam Lee</Text>
    </HoverCard.Content>
  </HoverCard>
</HoverCardProvider>

{/* An image across the top, with more padding */}
<HoverCard>
  <HoverCard.Trigger asChild>
    <Link href="/people/jane">@jane</Link>
  </HoverCard.Trigger>
  <HoverCard.Content size="lg">
    <HoverCard.Media>
      <img src="/people/jane/banner.jpg" alt="" />
    </HoverCard.Media>
    <Text weight="semibold">Jane Doe</Text>
  </HoverCard.Content>
</HoverCard>

{/* Off for a row that doesn't need a preview */}
<HoverCard disabled>
  <HoverCard.Trigger asChild>
    <Link href="/people/jane">@jane</Link>
  </HoverCard.Trigger>
  <HoverCard.Content>
    <Text size="sm">Never shown</Text>
  </HoverCard.Content>
</HoverCard>

{/* Controlled open state */}
function Example() {
  const [open, setOpen] = useState(false);
  return (
    <HoverCard open={open} onOpenChange={setOpen}>
      <HoverCard.Trigger asChild>
        <Link href="/people/jane">@jane</Link>
      </HoverCard.Trigger>
      <HoverCard.Content>
        <Text size="sm">{open ? "Open" : "Closed"}</Text>
      </HoverCard.Content>
    </HoverCard>
  );
}

{/* A native <a> attribute, passed straight through: offer the link as a download */}
<HoverCard.Trigger href="/people/jane.vcf" download>@jane</HoverCard.Trigger>
```
