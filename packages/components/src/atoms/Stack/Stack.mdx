<VisuallyHidden asChild><h2>Intro</h2></VisuallyHidden>

<ComponentHeader title="Stack" tier="Atom" />

A flex layout primitive for stacking children vertically or horizontally with a consistent,
token-driven `gap` — the standard way to space a group of elements without hand-writing margins.
**Polymorphic** (see [`Box`](/?path=/docs/atoms-layout-box--docs) for the full explanation of what
that means): renders a `div` by default, but `as` lets it render a real `<ul>`, `<nav>`, or any
other element/component while keeping Stack's own flex-layout behavior. `direction`, `align`,
`justify`, `wrap`, and `gap` each accept a single value or a mobile-first responsive map keyed by
breakpoint (e.g. `{ base: "column", md: "row" }`), matching `Grid`'s own `columns` prop — the
standard way to express "stack on mobile, row on desktop."

### Import

```tsx
import { Stack } from "@dbm-design-system/components";
```

## Usage guidelines

<div className="dbm-do-dont-grid">
<Callout tone="success" title="Do">

- Use `Stack` as the default way to space a group of elements — `gap` is a real token step, not a
  guessed margin value.
- Pass a responsive `direction` map (`{ base: "column", md: "row" }`) when a layout needs to
  reflow from stacked-on-mobile to side-by-side-on-desktop, rather than building two separate
  layouts.
- Pass `divider` (typically a real [`Divider`](/?path=/docs/atoms-layout-divider--docs)) instead
  of hand-interleaving a separator element between every child yourself.

</Callout>
<Callout tone="danger" title="Don't">

- Don't reach for `Stack` to build a 2-dimensional layout (rows *and* columns together) —
  that's [`Grid`](/?path=/story/molecules-layout-grid--default-columns), which Stack's own
  single-axis `gap` mechanism doesn't attempt to replace.
- Don't hand-write `margin-block-end`/`margin-inline-end` on children to fake a gap — `gap`
  already expresses this as a single token-driven prop, and doesn't leave a dangling margin after
  the last child the way manual per-child margins do.
- Don't expect a `divider` with `orientation="vertical"` to have height on its own inside a
  `direction="row"` Stack with no other sized content — see
  [`Divider`](/?path=/docs/atoms-layout-divider--docs)'s own Accessibility/Don't notes on this
  exact caveat.

</Callout>
</div>

## Best practices

- Prefer `gap` over `divider` for plain visual spacing — reach for `divider` only when a real,
  visible separator line belongs between items, not as a spacing trick.
- Treat `direction`'s responsive-map form as the default way to build a layout that reflows across
  breakpoints, rather than rendering two different `Stack` trees behind a media query yourself.
- Treat `as` the same way you'd treat choosing a native HTML tag directly — `Stack` imposes no
  semantics of its own beyond layout, so pass `as="ul"`/`as="nav"` whenever the content is
  genuinely a list or a navigation region.

## Accessibility

<Callout tone="info" title="No built-in semantics — as is what makes this accessible">

`Stack` sets no ARIA attributes and imposes no accessibility semantics of its own — the same as
[`Box`](/?path=/docs/atoms-layout-box--docs). Accessibility is entirely a function of which
element `as` renders and what real semantic structure the children provide; a genuine list of
items should use `as="ul"` with `<li>` children rather than the default `div`.

</Callout>

## Code examples

```tsx
// Stack on mobile, row on desktop
<Stack direction={{ base: "column", md: "row" }} gap={4} align="center">
  <Icon />
  <Text>Label</Text>
</Stack>
```

```tsx
// A real Divider automatically inserted between every child
<Stack direction="row" align="center" divider={<Divider orientation="vertical" />}>
  <span>One</span>
  <span>Two</span>
  <span>Three</span>
</Stack>
```

```tsx
// A native <div> attribute (title) passed straight through
<Stack title="Item group" gap={2}>
  <Badge>New</Badge>
  <Badge>Sale</Badge>
</Stack>
```
